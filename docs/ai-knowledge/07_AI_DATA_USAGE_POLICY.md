# 07 AI DATA USAGE POLICY（MICHI AI のデータ利用方針）

| 項目 | 内容 |
|---|---|
| 目的 | MICHI AI（利用者向けの推薦・プラン生成）が、蓄積データをどう使い、何を使わないかを定める |
| 区分 | **POLICY** |
| Version | 1.0.0 |
| 最終更新 | 2026-10-05 |
| 変更権限 | 人間（プロジェクト責任者）のみ |
| 関連文書 | `02`（情報の種類）、`03`（データ）、`04`（個人情報）、`06`（現地情報） |

> この文書の「MICHI AI」は、利用者に推薦を返すプロダクト内のAIを指す。
> 社内で働く AI社員（`.claude/agents/`）の権限は `04_SECURITY_POLICY.md` 4節を参照。

## 1. 基本構造

```text
公式情報
＋ 外部API
＋ 実際の旅行ルート
＋ 旅行者コメント
＋ Likes / Saves / Want to go
＋ 現地報告（直近のもの）
＋ ユーザー条件
        ↓
     MICHI AI
        ↓
  旅行者向け推薦
```

## 2. 原則

| 番号 | 原則 | 重要度 |
|---|---|---|
| A-1 | 事実データとAI推論を分ける。AIの出力を事実データとして保存・表示しない | 【MUST】 |
| A-2 | AIに事実を推測させない（例：「この店には英語対応スタッフがいます」） | 【MUST NOT】 |
| A-3 | AIが推薦に使う場所は、実在を確認できるデータ（外部API、共通Place）に限る | 【MUST】 |
| A-4 | データがない項目は「不明」として渡し、AIに埋めさせない | 【MUST】 |
| A-5 | 現地報告を渡すときは、新しさと件数を併せて渡す（`06`） | 【MUST】 |
| A-6 | AIに必要以上の個人情報を渡さない（3節） | 【MUST NOT】 |
| A-7 | 計算で決まるもの（時刻、合計金額、移動時間）は、AIではなくプログラムで計算する | 【SHOULD】 |
| A-8 | AIの出力は、利用者に見せる前に検証する（候補外の場所、時間・予算の逸脱） | 【SHOULD】 |
| A-9 | 推薦の理由を、利用者が確かめられる形で示す（どの旅行者データに基づくか） | 【SHOULD】 |

［事実］既存のプラン生成は A-3、A-4、A-7、A-8 に沿った作りと文書に書かれている（`mikke-supabase-backend/README.md`「AIプラン生成の流れ」：場所は候補の enum に固定、時刻はサーバーが計算、営業時間が不明なら `unknown`、最終検証 `validatePlan`）。

## 3. AIに渡すデータ

| 渡してよい【MAY】 | 渡してはならない【MUST NOT】 |
|---|---|
| 旅行条件（日程、時間、予算、人数、移動手段） | メールアドレス |
| 嗜好（興味、旅のスタイル、言語） | 氏名、電話番号、住所 |
| 関連する旅行データ（ルート、場所、コメント、反応の傾向、現地報告） | 詳細な位置履歴 |
| 処理に必要な範囲の現在地（その場の検索のため。保存しない） | 認証情報、決済情報 |
| 国・言語などの粗い属性（推薦に必要な場合） | 推薦に必要のないセンシティブ情報 |

- 【SHOULD】利用者を識別する値を渡す必要があるときは、内部ID等の仮名にする
- 【SHOULD】旅行者コメントを渡すときは、投稿者を特定できる情報を外す
- 【MUST】外部の AI API へ送る内容は、上の表の範囲に限る

## 4. 蓄積データの使い方

| データ | 使い方 |
|---|---|
| 実際の旅行ルート | 場所の順番・滞在時間・組み合わせの根拠 |
| Likes / Saves / Want to go | 人気・関心の根拠。属性別（例：初訪日、カップル）の傾向 |
| 旅行者コメント | 推薦理由の根拠、注意点の提示 |
| 現地報告 | 新しいものを優先し、古いものは信頼度を下げて使う |
| 公式情報・外部API | 住所・営業時間などの基礎情報 |

- 【MUST】件数が少ないデータから一般化しない（例：1人の報告を「外国人に人気」としない）
- ［TODO］「少ない」の基準は未決定

## 5. AI社員への適用

AI社員が調査・文書作成でAIの推論を使う場合も、同じ考え方を適用する。

- 事実には根拠（URL、ファイルのパス）を付け、推測は「推測」と書く（`CLAUDE.md` 4節）
- 利用者の個人情報を、外部のサービスやWeb検索の問い合わせに含めない
