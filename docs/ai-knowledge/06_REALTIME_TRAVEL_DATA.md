## 1. 対象とする情報

Google Maps 等にもある住所・営業時間ではなく、外国人旅行者の目線の情報。

| 分類 | 例 | 変わりやすさ |
|---|---|---|
| 言語 | English menu、English-speaking staff、券売機が日本語のみ | 中 |
| 注文・利用 | Ordering difficulty、外国人でも入りやすいか、初訪日でも利用しやすいか | 中 |
| 支払い | Payment methods（クレジットカードが使えたか） | 中 |
| 混雑 | Wait time、Crowd | 高（数時間で変わる） |
| 営業 | 臨時休業など | 高 |
| 体験 | 旅行者コメント、実際の滞在時間（予定より短い／長い） | 低〜中 |
| 移動 | 移動・乗換の難易度 | 低〜中 |

## 2. 原則

| 番号 | 原則 | 重要度 |
|---|---|---|
| R-1 | 現地情報を固定の属性（例：`English-speaking staff: Yes`）として持たない。**報告**として持つ | 【MUST】 |
| R-2 | 報告には、いつ・何人から・どこからの情報かを持たせる（3節） | 【MUST】 |
| R-3 | 古い情報と新しい情報を、同じ信頼度で扱わない | 【MUST NOT】 |
| R-4 | 変わりやすい情報ほど、時間の経過で信頼度を下げる | 【MUST】 |
| R-5 | AIが現地情報を事実として生成しない。報告のない項目は「情報なし」とする | 【MUST NOT】 |
| R-6 | 表示するときは、新しさと報告件数を利用者に見せる | 【SHOULD】 |
| R-7 | 報告する人の負担を小さくする（選択式、短時間） | 【SHOULD】 |
| R-8 | 現地にいたことの確認に現在地を使っても、詳細位置は保存しない（`04` S-11） | 【MUST】 |

## 3. 報告が持つべき項目

| 項目 | 意味 | 必須 |
|---|---|---|
| `reported_at` | 報告された時刻 | 必須 |
| report count | 同じ内容を報告した人数 | 必須（集計で求めてもよい。原本の報告は残す） |
| `source` | 情報の出どころ（旅行者の現地報告／旅行者の事後コメント／公式情報／外部API） | 必須 |
| `confidence` | 信頼度。新しさ・件数・現地確認の有無から決める | 必須 |
| `expires_at` | この時刻以降は表示しない、または「古い」と示す | 必要なら |
| 現地確認済み | 現地にいた人からの報告かどうか（真偽のみ） | 【SHOULD】 |

表示の例:

```text
English-speaking staff reported
2 hours ago · 3 travelers confirmed
```

## 4. 時間による信頼度

［方針］時間の経過で信頼度を下げる、という考え方を採用する。

| 経過 | 扱い |
|---|---|
| 2時間前 | 高信頼 |
| 3日前 | 中程度 |
| 2週間前 | 参考 |
| 3か月前 | 古い可能性 |

## 6. AI社員の判断例

| 場面 | 対応 |
|---|---|
| 「この店は英語が通じるか」に答える材料が報告にない | 「情報なし」とする。推測で答えない |
| 3か月前の報告が1件だけある | 「3か月前に1人が報告」と時期・件数を付ける。現在の事実として書かない |
| 紹介文に現地情報の例を書く | 実データがなければ、架空の例であることを明記する |
| 調査で外部サイトの口コミを見つけた | MICHI の現地報告として扱わない。出典URLと確認日を付けた外部情報として扱う |
